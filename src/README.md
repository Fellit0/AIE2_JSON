## Описание проекта

Парсер и анализатор JSON-логов LLM

## Требования и окружение

Python 3.0+
Используются только встроенные библиотеки
Дополнительная установка пакетов не требуется

## Инструкция по запуску

python parse_llm_logs.py

## Обоснование инженерных решений

Порог в 1000 токенов выбран для выделения наиболее объемных и дорогих запросов, требующих оптимизации затрат.
Отказоустойчивость: Скрипт защищен от пустых файлов и невалидных JSON. Ошибки логгируются в stderr и с кодом возврата 1

## Пример вывода программы

27 18 1000

## Обоснование выбора дополнительной метрики и порога фильтрации

В качестве дополнительной метрики я выбрал медиану, так как она считает точнее, чем среднее арифметическое и устойчива к выбросам.
Медиана позволяет точнее оценить стабильность системы

Порог фильтрации зафиксирован на уроне 1000, помогая разделить запросы на легковесные и трудоемкие. Такой мониторинг важен для оптимизации затрат.
